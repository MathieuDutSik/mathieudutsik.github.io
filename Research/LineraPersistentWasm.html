Persistent WebAssembly instances in Linera

In the Linera protocol, every message, operation or event stream processed by a contract used to instantiate the contract, run it and finalize it. This pull request keeps the contract instances alive for the whole block, and uses snapshots of the running Wasm machine to roll back a failed transaction.
