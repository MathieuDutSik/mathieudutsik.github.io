Interactive Tools

Computations on this page run locally in your browser. Results are exact.

Copositivity test

A real symmetric matrix A is copositive if vTA v ≥ 0 for every vector v with non-negative entries. When the matrix is not copositive the tool returns a non-negative witness vector v with vTA v < 0.

Enter entries as integers (3, -2) or rationals in p/q form (1/2, -7/3). You can also upload a text file with the format:

nRows nCols
A11 A12 ... A1N
A21 A22 ... A2N
.
.
AM1 AM2 ... AMN
