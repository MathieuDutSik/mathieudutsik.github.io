Copositivity test

A real symmetric matrix A is copositive if vTA v ≥ 0 for every vector v with non-negative entries. When A is not copositive the tool returns a witness vector v ≥ 0 with vTA v < 0.

Copositive factorization test

A real symmetric matrix A admits a copositive factorization if it can be written as

A = α₁ v₁ v₁ᵀ + α₂ v₂ v₂ᵀ + ... + αₘ vₘ vₘᵀ

with vi ∈ ℤ≥0n and αi ∈ ℚ≥0. (Matrices with such a factorization are also called completely positive.) On success the tool returns the family (αi, vi). On failure it returns a copositive certificate matrix C with ⟨C, A⟩ < 0, which proves no such factorization exists.

Shortest-vector realizability

Given an integer matrix whose rows are vectors in ℤn, decide whether there exists a positive-definite quadratic form for which this set is exactly the family of (orbits of) shortest vectors. On success the tool returns one such Gram matrix G.

The underlying routine is SHORT_TestRealizabilityShortestFamily; in practice the input must be square (a basis of n vectors in n-dim) — non-square inputs may not be accepted by the kernel.

Shortest-vector automorphism group

Given an integer matrix whose rows are vectors in ℤn, compute the subgroup of GL(n, ℤ) that stabilises the configuration (as a set, up to sign). The tool returns a list of integer-matrix generators of that group.

Same shape constraint as the realizability tool — square inputs work, arbitrary rectangular inputs are not guaranteed to.

Gram-matrix canonicalization

Given a positive-definite rational symmetric matrix G (a Gram matrix), compute an integer basis change B ∈ GL(n, ℤ) so that B · G · BT is a canonical representative of G's GL(n, ℤ)-orbit. Two Gram matrices have the same canonical form iff they are integrally equivalent.

Packing and covering density of a polytope

For a full-dimensional polytope P ⊂ ℝn, compute the packing scalar α, the largest α such that the translates αP + z, z ∈ ℤn, have pairwise disjoint interiors, and the covering radius μ, the smallest μ such that the translates μP + z cover ℝn. The corresponding densities are

packing density  = αn vol(P)  ≤ 1
covering density = μn vol(P)  ≥ 1

P need not be centrally symmetric. The tool also returns the contact vectors (the z for which αP and αP + z touch), a last covered point p and the lattice points on the boundary of the empty translate p − μP.

Enter one vector vi per row. The polytope is

  • Vertices: P = conv(v1, …, vM);
  • Inequalities: P = {x : vi · x ≤ 1 for all i}, which is bounded when 0 is in the interior of conv(v1, …, vM);
  • Zonotope: P = v1[0,1] + … + vM[0,1].

The covering radius is found by an exact branch and bound, which can take a while from dimension 3 on; the computation runs in the background and can be stopped.

Minimal covering polytope test

A polytope P ⊂ ℝn is covering if P + ℤn = ℝn, and minimal covering if moreover no convex body strictly contained in P is covering (Codenotti, Freyer, Krivokuca, Minimal covering bodies and Brunn–Minkowski type inequalities for the covering radius). The test is exact and local: P is minimal covering exactly when no vertex of P can be cut off keeping the covering. When P is covering but not minimal, the tool lists the vertices that can be cut; when P is not covering, it gives its covering radius μ > 1.

The polytope P is entered as in the packing and covering tool: one vector vi per row, read as its vertices, as inequalities vi · x ≤ 1, or as zonotope generators.

Find a minimal covering polytope

Given a polytope P with covering radius μ ≤ 1 (so that P is covering), find a minimal covering polytope Q contained in μP, and so in P. Two methods:

  • Grid (default): Q is the convex hull of a set of candidate points, the vertices of μP and its points in (1/D)ℤn, from which points are dropped as long as the hull stays covering. D is N times the lcm of the denominators of the vertices of μP. When the result is not proved minimal, the finer grids (1/2D)ℤn, (1/3D)ℤn, … are tried, up to the given number of rounds.
  • Reduction: repeatedly remove a vertex, push a facet inward, or cut a vertex as deep as the covering allows. Each step is exact, but in dimension 3 the cuts can go on without end, so the number of steps is bounded.

The result says whether Q is proved minimal. Dimension 2 takes seconds; dimension 3 can take minutes.

The polytope P is entered as in the packing and covering tool: one vector vi per row, read as its vertices, as inequalities vi · x ≤ 1, or as zonotope generators.
