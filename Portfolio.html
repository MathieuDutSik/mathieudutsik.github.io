Blockchain & systems engineering

Persistent WebAssembly instances in Linera

In the Linera protocol, every message, operation or event stream processed by a contract used to instantiate the contract, run it and finalize it. This pull request keeps the contract instances alive for the whole block, and uses snapshots of the running Wasm machine to roll back a failed transaction.

…(Read More)(Read Less)

Linera is a blockchain built on microchains: every user or application can own a chain, and the chains talk to each other through asynchronous messages. Smart contracts are compiled to WebAssembly and run in a virtual machine (wasmer or wasmtime) inside the validators and the clients. A block typically contains many incoming messages and operations, and several of them often target the same application.

In the original execution model, each of these was handled in isolation: the contract was instantiated, its state was loaded from storage, the entry point was run, and the contract was finalized and its state stored back. For a busy application, such as an order book receiving a burst of bids and asks, the same contract was thus loaded and saved dozens of times in one block. Interactions between contracts made it worse: when contract A handles a message that makes it call contract B, which in turn calls A, every step paid the full set-up cost.

The pull request changes this model: a contract instance is created the first time it is needed in a block and stays alive until the block ends. The SDK functions load and store are then called once per application and per block. This also gives a natural place for checks that only make sense at the level of the block. In a flash loan, contract A borrows tokens from a bank and contract B pays them back; if the bank's terminate function sees that the loan has not been repaid, the block cannot be created.

The difficulty is checkpointing. An incoming bundle of messages may fail, and its effects must then be undone. Saving the chain state is no longer enough, since the Wasm machine itself now holds state across transactions. The solution is to take snapshots of the running Wasm instances, implemented for both wasmer and wasmtime. They are small (about 1.1 MB for the matching engine), fast, and cost no fuel, whereas a software load/store pair costs around 25,000 fuel units even for a trivial counter contract. In the browser, where Wasm instances cannot share memory, the snapshots are serialized and the instances are wound down after every transaction.

On a benchmark where 50 bids and 50 asks are sent to the same matching-engine application, processing the inbox goes from 760 ms to 413 ms. Since the contract API and the cost structure both change, this is a protocol-level change, which could not be backported to the running testnet.

EVM Support in Linera

I implemented Ethereum Virtual Machine (EVM) support within the Linera protocol, allowing Ethereum-based applications to run on microchains. The implementation supports complex protocols like Morpho using specialized precompiles.

…(Read More)(Read Less)

Most smart contracts in use today are written in Solidity and compiled to EVM bytecode. A new blockchain that only accepts its own contract format asks developers to rewrite and re-audit all that code, which they rarely do. Supporting the EVM inside Linera lets existing Ethereum applications and tools be reused, while Linera keeps its own WebAssembly runtime for native applications.

The implementation lives in the execution layer of the protocol (linera-execution/src/evm) and is built on revm, the Rust implementation of the EVM. The main work is to connect two very different models. Ethereum has a single global state with synchronous calls between contracts. Linera has many microchains, each with its own state, and communication between chains goes through asynchronous messages.

The features that have no Ethereum equivalent, such as cross-chain messaging and multi-chain coordination, are exposed to Solidity code through precompiles: special addresses that, when called, run code from the host instead of EVM bytecode. A Solidity contract can thus use the multi-chain features of Linera with ordinary function calls.

Compatibility was a guiding principle. The only significant difference with Ethereum is the scheme for contract addresses, which has to fit the way Linera identifies applications. Everything else behaves as on Ethereum, so standard compilers and tooling can be used unchanged.

The implementation was validated on real DeFi code: the Morpho lending protocol runs on Linera through this EVM layer. Morpho combines many interacting contracts, oracles and callbacks, which makes it a demanding test of correctness.

Geophysical modelling

Bathymetry smoothing

We proposed a new linear programming method for smoothing sea depths in terrain-following oceanic models. This approach performs significantly better than existing methods by maintaining stability while staying near the real bathymetry.

…(Read More)(Read Less)

Many ocean circulation models, such as ROMS, use terrain-following (sigma) coordinates: each water column is divided into the same number of vertical layers, which follow the shape of the sea floor. This gives good resolution of the bottom boundary layer, but it has a well-known weakness. Where the depth changes quickly between neighboring grid cells, the layers become steep, and the horizontal pressure gradient is the difference of two large terms that do not cancel exactly. The error creates artificial currents, which can spoil the solution or make the model unstable.

The Adriatic Sea is a difficult case. The northern part is a shallow shelf, the southern part has a basin deeper than 1200 m, and the eastern coast is made of islands and narrow channels. Using the raw bathymetry is not possible, so the depth has to be smoothed. One wants to keep the smoothed bathymetry as close as possible to the real one, since every change moves islands, channels and slopes, and so the circulation.

A standard measure of steepness is the roughness factor r0 = |hi − hj| / (hi + hj) between adjacent cells i and j, which must stay below a threshold for the model to be stable. The usual smoothing methods are local filters, applied again and again until the threshold is met. They have no control over the total change, and they modify the bathymetry far more than needed, even in regions that were already smooth.

The key observation is that the condition r0 ≤ r is linear in the depths: it is equivalent to (1 − r) hi ≤ (1 + r) hj and the symmetric inequality. We can therefore search for the depths h that satisfy all the roughness constraints and are as close as possible to the raw depths in the L1 sense, which is a linear program. Further requirements are also linear, for example keeping some depths fixed or allowing the depth only to increase, and are added easily. The linear program finds the smallest possible change that satisfies the constraints, and in practice it changes only a small part of the domain.

On the Adriatic, the method gives a bathymetry that is stable and much closer to the real one than the classical methods.

Coupling of circulation and wave models

I coupled the circulation model ROMS with the wave model WWM to study their interactions. This coupling revealed significant effects on wave height in regions like the Bura jet and the Istrian coast.

…(Read More)(Read Less)

The ocean circulation and the surface waves are usually computed by two different models. A circulation model such as ROMS solves the primitive equations for currents, temperature and salinity. A spectral wave model such as WWM (Wind Wave Model, developed by Aron Roland) evolves the energy spectrum of the waves, for every frequency and direction, under wind forcing, propagation, breaking and bottom friction. Each model acts on the other, but in most operational systems they run separately.

In a coupled system the two models exchange fields during the run. The circulation model gives the wave model the currents and the water level: the waves are refracted and Doppler-shifted by the currents, and their speed depends on the depth. The wave model gives back the radiation stress and the Stokes drift, which drive currents near the coast, and changes the stress that the wind exerts on the sea surface and the friction on the bottom. I implemented this two-way coupling between ROMS and WWM, with the exchange of fields between the two parallel codes and their different grids.

The Adriatic Sea is a good test. In winter it is struck by the Bura (bora), a cold and violent wind from the north-east that comes down the Dinaric mountains in narrow jets. These jets create strong currents and steep, short waves over a small sea. The hindcast of these events showed that the coupling reduces the significant wave height inside the Bura jets, where waves and currents run in the same direction, and increases it in front of the Istrian coast; the differences reach about 10 cm. Such changes matter for storm forecasts, for coastal erosion and for shipping.

This work was continued in several directions: the operational wave forecast of the Adriatic, the modelling of North Atlantic storms, and an implicit, domain-decomposed parallel scheme for the wave model WAVEWATCH III, used for large-scale hurricane modelling.

Mathematical physics

Ginzburg Landau model

I established the phase diagram for the bulk Ginzburg-Landau model of superconductivity using complex hermitian geometry. This included establishing the Abrikosov asymptotic expansion for minimal energy states.

…(Read More)(Read Less)

The Ginzburg–Landau model describes a superconductor by two unknowns: a complex wave function φ, whose modulus |φ|2 is the density of superconducting electrons, and the magnetic field inside the material. The state of the material minimizes an energy that depends on two parameters, the exterior magnetic field Hext and a structural constant κ of the material. My PhD thesis studied the bulk version of the model, in which the material fills the whole space and the states are periodic with respect to a lattice.

Three kinds of states appear. In the pure state |φ| = 1, the material is superconducting everywhere and expels the magnetic field. In the normal state φ = 0, superconductivity is destroyed and the field goes through the material. In the mixed state both coexist: the field enters along vortex lines, around which φ vanishes, and these vortices arrange themselves in a periodic lattice. This is the Abrikosov lattice, predicted by Abrikosov in 1957 and observed later in type II superconductors.

The first result is the phase diagram: for every value of (κ, Hext), which of the three states has the lowest energy. The physicists' picture had been obtained by formal arguments, and my thesis proved its classical form. The main tool comes from complex geometry. When the energy is written on the torus defined by the lattice, the wave function becomes a section of a line bundle, and the Bochner–Kodaira–Nakano formula gives the estimates that separate the regions of the diagram.

The second result concerns the transition from the normal state to the mixed state. Near the critical field the solutions bifurcate from φ = 0, and the minimal energy and the minimizing states have an asymptotic expansion, first computed formally by Abrikosov. I proved this expansion. The leading term is given by the lowest Landau level, a space of holomorphic sections described by theta functions, and the choice of the vortex lattice comes from the minimization of a quantity of the form ⟨|φ|4⟩ / ⟨|φ|2⟩2 over this space.

Plane graphs, polycycles & combinatorial structures

Elementary polycycles and Face regular maps

We classified elementary elliptic (R,q)-polycycles to create an efficient enumeration technique. This method was successfully applied to the classification and study of face-regular spheres and tori.

…(Read More)(Read Less)

A (R,q)-polycycle is, roughly, a piece of a plane graph whose faces are i-gons with i in a set R, and whose vertices have degree q, except on the boundary of some holes. A typical example is a patch of a fullerene made only of pentagons. The polycycle is called elliptic, parabolic or hyperbolic if 1/q + 1/r − 1/2 is positive, zero or negative, where r is the largest element of R. Elliptic polycycles are those of positive curvature: there are few of them, and they are the pieces that make a surface close up into a sphere.

Polycycles can be glued along their boundaries. An edge of a hole is open if both its end vertices have degree less than q, and a polycycle is elementary if it cannot be cut into smaller polycycles along open edges. Every polycycle is then obtained in a unique way by gluing elementary ones. With Michel Deza and Mikhail Shtogrin, we enumerated all elliptic elementary polycycles, that is the elementary ({2,3,4,5},3)-, ({2,3},4)- and ({2,3},5)-polycycles. They consist of finitely many sporadic examples and a few infinite series.

This list turns the study of a plane graph into a puzzle with known pieces. Take a 3-valent sphere whose faces are pentagons and q-gons, and look at the subgraph formed by its pentagons. It is a (5,3)-polycycle, so it is obtained by gluing elementary pieces from the list. The possible arrangements of the pentagons are then found by hand or by computer.

We applied this method to face-regular maps. A 3-valent map on the sphere or the torus with p-gonal and q-gonal faces is called pRi if every p-gonal face is adjacent to exactly i p-gonal faces, and qRj is defined in the same way. These classes include many structures studied by chemists, such as fullerenes in which the pentagons are isolated. For each class, we determined whether it is empty, finite or infinite, and gave the complete list when it is finite. The figures on the details page show two such spheres: a (5,8)-sphere 8R2 and a (5,9)-sphere 9R0. This work forms a large part of the book Geometry of Chemical Graphs with Michel Deza.

Zigzags and central circuits

We studied the structure of zigzags and central circuits in 3- and 4-valent plane graphs. This led to classification results for 2-connected graphs and new insights into the Goldberg-Coxeter construction.

…(Read More)(Read Less)

Walk along the edges of a plane graph, turning alternately left and right at every vertex. The circuit obtained is a zigzag: any two consecutive edges belong to a common face, but no three do. In a 4-valent graph one can instead go straight on at every vertex, which gives a central circuit. Every edge lies on exactly two zigzags (or on one central circuit), so these circuits form a canonical family of curves in the graph. They encode a lot of its structure, which makes them useful for the plane graphs of chemistry, such as fullerenes.

The z-vector of a graph lists the lengths of its zigzags and the way they intersect. With Michel Deza, we studied the z-vectors of 3-valent plane graphs with faces of size at most 6, and of 4-valent plane graphs with faces of size at most 4. A railroad is a circuit of hexagons (or squares) in which every face is adjacent to its two neighbors on opposite edges: it is a strip bounded by two parallel zigzags. A graph without railroad is tight. We completely described the zigzag structure of the (3,6)-spheres; for the (4,6)-spheres we described the possible symmetry groups, classified the tight graphs whose zigzags are simple, and proved that a tight graph has at most 9 zigzags. We also classified the graphs of these classes that are 2-connected but not 3-connected, and gave all possible symmetry groups. Railroads also gave rise to new extremal problems and to knot-like phenomena in fullerenes.

The Goldberg–Coxeter construction takes a 3- or 4-valent plane graph G and a pair of integers (k,l), and produces a larger graph GCk,l(G) with the same symmetry. It is the construction behind geodesic domes and the icosahedral capsids of viruses. We computed the zigzag and central circuit structure of GCk,l(G) from that of G. For this we introduced a product on pairs (k,l) and a finite index subgroup of SL2(Z), which together predict how the circuits split.

These results are collected in the book Geometric Structure of Chemistry-relevant Graphs: zigzags and central circuits (Springer, 2015), with Michel Deza and Mikhail Shtogrin.

Simplicial complexes

All simplicial n-complexes with specific face containment properties have been classified. This work provides a classification based on the partitions of set elements related to the dimension of the complex.

…(Read More)(Read Less)

A closed simplicial n-complex is built by gluing n-dimensional simplices along their faces. One way to measure its local shape is the link of its (n−2)-dimensional faces. In a triangulated surface (n = 2), the (n−2)-faces are the vertices, and the link of a vertex is the cycle of triangles around it; its length is the degree of the vertex. Large links mean negative curvature, short links mean strong positive curvature.

With Michel Deza and Mikhail Shtogrin, we studied the extreme case of short links, where every (n−2)-face lies in only 3 or 4 n-simplices. One expects such a strong condition to leave few possibilities, and indeed the complexes are completely classified. Each of them is determined by its characteristic partition, a partition of the set {1, …, n+1}. A part with k elements corresponds to the boundary of a k-dimensional simplex, and the complex is the join of these boundaries.

For surfaces, the three partitions of {1,2,3} give the three triangulations of the sphere whose vertices all have degree 3 or 4:

  • {1,2,3}: the tetrahedron, with all vertices of degree 3;
  • {1,2}, {3}: the triangular bipyramid, with two vertices of degree 3 and three of degree 4;
  • {1}, {2}, {3}: the octahedron, with all vertices of degree 4.

In higher dimensions the same rule produces, for example, the boundary of the (n+1)-simplex and the boundary of the cross-polytope, at the two ends of the list.

The same paper considers cubical complexes with short links, and the embedding of the skeletons of these complexes into hypercubes. This is one of several works with Michel Deza on the L1-embedding of graphs coming from geometry, of which the Wythoff polytopes below are another example.

Polytopes, tilings & polyhedral computation

Space fullerenes

Space fullerenes are tilings of Euclidean space by fullerenes, occurring in metallurgy, crystallography, and optimization. I performed the enumeration of small space fullerenes and new Frank-Kasper structures.

…(Read More)(Read Less)

A fullerene is a 3-valent polyhedron whose faces are pentagons and hexagons, like the C60 molecule. A space fullerene is a tiling of three-dimensional space by fullerenes in which every edge is shared by three tiles and every vertex by four, the way soap bubbles meet in a foam. Only four fullerenes can occur in such a tiling: the dodecahedron and the polyhedra with 14, 15 and 16 faces, which have 2, 3 and 4 hexagons.

Pieces of periodic space fullerenes; the first one is the A15 structure.

These tilings appear in several sciences under different names. In metallurgy they are the Frank–Kasper phases of complex alloys, where the tiles are the coordination polyhedra of the atoms: the A15 phase of Cr3Si, the cubic Laves phase MgCu2, the σ phase and others. In chemistry they describe the frameworks of clathrate hydrates and zeolites, where water or silicon atoms sit at the vertices and small molecules are trapped in the cells. In geometry they are candidates for the Kelvin problem, which asks how to divide space into cells of equal volume with the least surface area: the Weaire–Phelan foam, which improved on Kelvin's 1887 solution, is the A15 structure.

The known Frank–Kasper structures had been found one by one in real crystals. With Olaf Delgado-Friedrichs and Michel Deza, I designed a computer enumeration of periodic space fullerenes with a small number of tiles in a fundamental domain. The search builds the tiling step by step, using the strong local rules on edges and vertices, and recognizes identical structures with tools for the topology of periodic tilings. It found many new Frank–Kasper structures, and the second paper extends the search to larger fundamental domains. The resulting list is a catalogue of candidate structures for crystallographers.

Polyhedral computation with symmetry

I developed highly efficient algorithms for computing the dual description of polytopes with symmetry. This led to the classification of 10,916 perfect forms in dimension 8, a feat previously deemed impossible.

…(Read More)(Read Less)

A polytope can be given in two ways: by its vertices, or by the inequalities of its facets. Going from one description to the other is the dual description problem, a basic task of computational geometry, solved in general by programs such as lrs and cdd. The size of the output can grow exponentially, and for the polytopes that appear in the geometry of numbers or in combinatorial optimization these programs often run out of memory or time.

These polytopes, however, have very large symmetry groups, and only one facet per orbit is needed. I developed, step by step, a set of methods that work up to symmetry. The adjacency decomposition method, which comes from Christof and Reinelt, explores the graph of the orbits of facets: starting from one facet, it computes the facets adjacent to it, keeps those in new orbits, and continues. Each step is a dual description problem in one dimension less, with the stabilizer of the facet as symmetry group, so the method can be applied recursively. Making this work at scale required many components: fast tests of equivalence of facets under the group, choosing at each step between a direct computation and a further decomposition, computing the symmetry group of a polyhedron with graph automorphism software, and running the computation in parallel. The methods are now in the C++ library polyhedral_common.

Two computations show what this makes possible:

  • Perfect forms in dimension 8. Perfect forms are the vertices of Voronoi's theory of lattice packings (see the Hermite constant below). With Achill Schürmann and Frank Vallentin, we classified them in dimension 8 and found 10,916 of them. The hardest step was the dual description of a cone in dimension 36 with 120 extreme rays, coming from the lattice E8: it has about 25,075,566,937,584 facets, which fall into 83,092 orbits. The classification was later used to compute the cohomology of GLN(Z) for N ≥ 8 and to prove that the algebraic K-group K8(Z) is trivial.
  • The contact polytope of the Leech lattice. The Leech lattice, in dimension 24, is the most remarkable lattice of the geometry of numbers. Its contact polytope is the convex hull of its 196,560 minimal vectors. It has 1,197,362,269,604,214,277,200 facets, in 232 orbits under the automorphism group.

Wythoff polytopes

The Wythoff construction was used to determine L1-embeddable polytopes derived from regular polytopes. It was also applied to compute the third homology group of the Mathieu group M24.

…(Read More)(Read Less)

The Wythoff construction takes an n-dimensional polytope P, not necessarily convex, and a non-empty subset S of {0, …, n}, and returns a new n-dimensional polytope W(P,S), called a Wythoffian. Its vertices correspond to the flags of faces of P whose dimensions are given by S. Many classical operations are special cases: S = {0} gives P itself, S = {n} its dual, S = {1} the medial polytope, and S = {0, …, n} the most truncated form. Applied to the regular polytopes, the construction produces many of the uniform polytopes, and it keeps the full symmetry group of P.

Embedding into hypercubes. A graph is L1-embeddable if its path metric, possibly multiplied by a constant, can be realized by points of a hypercube with the Hamming distance. This property has links with cuts, with optimization and with the design of interconnection networks, and only special graphs have it. With Michel Deza and Sergey Shpectorov, we studied the skeletons of the Wythoffians W(P,S) of the regular polytopes P. We obtained a list of the L1-embeddable ones that we conjecture to be complete, with explicit embeddings.

Homology of the Mathieu groups. The homology of a finite group G is computed from a free resolution of Z over the group ring ZG, which is hard to build for large groups. With Graham Ellis, we used the Wythoff construction to build such a resolution. If G acts on a Wythoff polytope, the polytope gives a contractible cell complex with a G-action, whose cells have known stabilizers. Perturbation techniques, implemented in Ellis' GAP package HAP, then turn it into an explicit free ZG-resolution. This gave, for example, H3(M24, Z) = Z12 and H5(M23, Z) = Z7 for the Mathieu sporadic simple groups. The method applies in principle to any finite group with a good geometric action.

Cube packings and tilings

We investigated periodic cube packings and tilings in Rn, proving extensibility theorems for dense packings. Our research provides lower bounds on non-extendible packings and explores their continuous parametrization.

…(Read More)(Read Less)

Consider packings of Rd by translates of the cube [0,2[d placed at integer positions, and periodic under the lattice 4Zd. Equivalently, we pack cubes of side 2 in a torus of side 4, which has room for exactly 2d cubes. When all 2d cubes are present, the packing is a tiling. Such tilings are much more varied than the regular one, since layers can slide against each other. They are closely related to Keller's conjecture, which says that every tiling of space by unit cubes has two cubes that share a full face, true in low dimensions and false in high dimensions.

A packing is non-extendible if no cube can be added to it, although it is not a tiling. Such packings exist: in dimension 3 there is a unique non-extendible packing with 4 cubes, half of the 8 that a tiling would have. With Yoshiaki Itoh and Alexei Poyarkov, we described cube packings by the cliques of an associated graph. This allowed us to classify them completely in dimension d ≤ 4 and to generate random examples in higher dimension. We proved that a packing with more than 2d − 3 cubes can always be extended to a tiling, and we gave a lower bound on the number of cubes of a non-extendible packing. We also studied the second moment, the average of the square of the number of cubes in a window of side 4, and proved that the regular tiling maximizes it.

This research grew out of the study of random sequential packing: put cubes one after another at random positions, as long as there is room. In one dimension this is Rényi's parking problem. In the discrete setting the result is always a non-extendible packing, and the question is how many cubes one expects. With Yoshiaki Itoh we also considered the continuous version, where the cubes can be placed at any real position. Surprisingly, it is still amenable to combinatorial methods: the packings are organized into finitely many combinatorial types, each with a continuous parametrization.

This work is collected in the book Random Sequential Packing of Cubes (World Scientific, 2011) with Yoshiaki Itoh. It was later continued with a study of the two-periodic cube tilings of R4 with Magdalena Łysakowska.

Lattices, quadratic forms & Delaunay geometry

The Hermite constant in dimension 9

We solved the lattice packing problem in dimension 9 by running Voronoi's algorithm to completion. We found all 2,237,251,040 perfect lattices in dimension 9, which shows that the Hermite constant γ9 equals 2.

…(Read More)(Read Less)

How densely can equal balls be packed in n-dimensional space, if their centers form a lattice? In dimension 2 the answer is the hexagonal packing, and in dimension 3 it is the familiar stack of cannonballs, as proved by Gauss. The density of the best lattice packing is measured by the Hermite constant γn. It was known only in dimensions 1 to 8, and in dimension 24 where the Leech lattice is optimal. Dimension 8 was settled in the 1930s by Blichfeldt, and no new dimension had been solved by this method since.

In 1908 Voronoi gave an algorithm that solves the problem in any dimension in finite time. He proved that a lattice of locally maximal density must be perfect: it is determined, up to scaling, by its set of minimal vectors. There are finitely many perfect lattices in each dimension, and Voronoi's algorithm enumerates them by walking on a graph whose vertices are the perfect forms. Each step requires the facets of a polyhedral cone. The difficulty is the size of the problem. There are 33 perfect lattices in dimension 7 and 10,916 in dimension 8 (see the polyhedral computation above), and dimension 9 was out of reach.

With Wessel van Woerden, we completed Voronoi's algorithm in dimension 9. There are exactly 2,237,251,040 perfect lattices up to similarity. Handling two billion objects required a highly optimized implementation: every new perfect form must be compared with the ones already found, and every step of the walk requires a polyhedral computation. As a corollary, the laminated lattice Λ9 gives the densest lattice packing in dimension 9, and the Hermite constant is γ9 = 2.

The classification also answers other questions. Extending a result of Watson from 1971, we determined the set of all possible kissing numbers of lattices in dimension 9: it is 2 · {1, …, 91, 99, 120, …, 129, 136}. The complete list of perfect forms is available on Zenodo.

Geometry of Numbers

We designed specific algorithms for enumerating Delaunay polytopes in lattices under symmetry. These polytopes form tessellations dual to Voronoi partitions, which are essential in computational geometry and physics.

…(Read More)(Read Less)

A lattice L is a discrete subgroup of Euclidean space, such as the integer points Zn or the centers of the hexagonal packing. Two tessellations of space are attached to it. The Voronoi cell of a lattice point is the set of points of space closer to it than to any other lattice point; its translates tile space. A sphere is empty if no lattice point lies inside it, and the convex hull of the lattice points on an empty sphere is a Delaunay polytope. The Delaunay polytopes also tile space, and the two tessellations are dual: the vertices of the Voronoi cell are the centers of the empty spheres.

Many properties of a lattice are read from these tessellations. The covering radius, which measures how well the lattice approximates every point of space, is the largest radius of an empty sphere. The quantizer constant, which measures the mean error when the lattice is used to round signals, is an integral over the Voronoi cell. The facets of the Voronoi cell give the closest vector problem, central in cryptography.

With Achill Schürmann and Frank Vallentin, we studied the computation of the Voronoi cell. On the negative side, we proved that computing the number of vertices of the Voronoi cell of a lattice given by a basis is #P-hard. On the positive side, we designed an algorithm that enumerates the Delaunay polytopes up to the symmetries of the lattice, walking from a Delaunay polytope to its neighbors across their facets. It works well in dimension up to about 12 and for highly symmetric lattices, where the symmetry group reduces the work by large factors. Our implementation was much faster than the computer algebra systems of the time, and we used it to compute the Voronoi cells, covering radii and quantizer constants of famous lattices.

These tools became the basis for later work on Voronoi cells: the classification of the 110,244 combinatorial types of five-dimensional Voronoi cells of lattices, the coloring of the Voronoi tessellation, and the Voronoi conjecture on parallelohedra.

Combinatorial types

Building on Fedorov's 1885 classification of 3D lattice Delaunay polytopes, I enumerated them in dimension 6. This research identified 6,241 distinct combinatorial types.

…(Read More)(Read Less)

Which polytopes can be Delaunay polytopes of a lattice? Two Delaunay polytopes have the same combinatorial type if their face lattices are isomorphic. In dimension 2 there are only two types, the triangle and the quadrilateral (Dirichlet, 1860). In dimension 3, Fedorov found five types in 1885. The classification was then extended by Erdahl and Ryshkov to dimension 4 (19 types), and by Kononenko to dimension 5 (138 types).

I extended it to dimension 6 and found 6,241 combinatorial types. The jump from 138 shows how quickly the complexity grows, and this classification is not possible by hand.

The method uses the hypermetric cone HYPn+1. A semimetric d on n+1 points is hypermetric if it satisfies the inequalities ∑ bi bj d(i,j) ≤ 0 for all integer vectors b with ∑ bi = 1. These inequalities define a polyhedral cone, and its faces are related to the Delaunay polytopes of n-dimensional lattices: a point of the cone gives an empty sphere, and the face containing it describes the Delaunay polytope. With Michel Deza, I had computed the full face structure of HYP7, a polyhedral computation with a large symmetry group, the symmetric group on 7 elements. Going through the faces of this cone and identifying the Delaunay polytopes they give, up to combinatorial isomorphism, produces the complete list in dimension 6.

Perfect Delaunay polytopes

Perfect Delaunay polytopes correspond to the extreme rays of the Erdahl polyhedral cone. I constructed an infinite series of them and classified those of dimension 7, of which there are exactly two.

…(Read More)(Read Less)

A Delaunay polytope can usually be deformed: if the lattice is changed slightly, the polytope changes shape but stays a Delaunay polytope. A Delaunay polytope is called perfect (or extreme) if this is impossible, that is, if every affine transformation that keeps it a Delaunay polytope is an isometry composed with a homothety. Perfect Delaunay polytopes are rare and rigid objects. Apart from the segment, they exist only in dimension n ≥ 6. The first example is the Schläfli polytope 221, with 27 vertices, in the root lattice E6; it is related to the 27 lines on a cubic surface. In dimension 7 there is the Gosset polytope 321 of E7. These polytopes play a role in the study of the covering maxima of lattices.

There are two polyhedral cones in this theory. In the hypermetric cone, extreme Delaunay polytopes correspond to extreme rays. In the Erdahl cone of degree 2 polynomials that are nonnegative on the integer points, perfect Delaunay polytopes correspond to extreme rays too. This makes them accessible to polyhedral computation.

My main results on these polytopes are:

  • an infinite series EDn of extreme Delaunay polytopes, one in every dimension n ≥ 6, which generalizes the Schläfli polytope; before, examples were known only in a few dimensions;
  • an adjacency method that finds new extreme Delaunay polytopes from a known one, by moving along the hypermetric cone and solving closest vector problems. It found 27 extreme Delaunay polytopes in dimension 8;
  • a complete classification in dimension 7, with a general enumeration algorithm based on the Erdahl cone: there are exactly two perfect Delaunay polytopes, 321 and the Erdahl–Rybnikov polytope. From this list we also obtained the 11 types of Delaunay simplices in dimension 7;
  • with Konstantin Rybnikov, perfect Delaunay polytopes derived from the Leech lattice, and perfect Delaunay polytopes that do not generate their lattice.

L-type domains and the lattice covering problem

Using semidefinite programming, we optimized covering densities over L-type domains. This allowed us to find record lattice coverings in dimensions 9 through 15 and classify thin algebraic number fields.

…(Read More)(Read Less)

The covering problem is the opposite of the packing problem. We cover space with balls of equal radius, so that every point lies in at least one ball, and want the thinnest covering, the one where points are covered as few times as possible on average. For lattice coverings, the radius needed is the covering radius of the lattice, which is the largest radius of its empty spheres. The problem is solved in dimension 2 and 3, and the best lattice covering is the lattice An* up to dimension 5. In higher dimensions only records are known.

Voronoi's second reduction theory gives the structure of the problem. The space of positive definite quadratic forms, that is of lattices up to isometry, is divided into polyhedral cones called L-type domains. All the lattices of one domain have the same Delaunay tessellation. Inside one L-type domain, the covering density can be computed from the Delaunay polytopes, and minimizing it is a convex problem that can be solved by semidefinite programming. If all L-type domains are known, solving each of these problems solves the lattice covering problem. In practice the number of domains explodes, and this works only up to dimension 5.

With Achill Schürmann and Frank Vallentin, we extended Voronoi's theory to quadratic forms in a linear subspace of the space of all forms, for example the forms that have a prescribed symmetry group. In such a subspace there are much fewer L-type domains, and the theory can be applied in much higher dimensions. Searching in suitable subspaces, we found new best known lattice coverings in all dimensions from 9 to 15.

The same theory applied to number theory: the subspaces given by totally real number fields allowed us to complete the classification of the totally real thin algebraic number fields, started by Bayer-Fluckiger and Nebe.

Related work continues today. With Sven Ahrend, we found a periodic point set that is not a lattice and beats the best lattice for the packing-covering constant in dimension five.
